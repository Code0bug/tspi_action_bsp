## 可关服务

- **S49ntp**：启动网络时间同步的脚本，用于系统校时。当前无网，可暂时关掉。已在 debug 跳过名单中。
- **S50usbdevice**：配置 USB 设备，包括启动 adb。出厂版本可以考虑关掉。本次结果里仍在启动，约 1.17s。
- **S50dropbear**：启动 ssh 服务，可以关掉。已在 debug 跳过名单中。
- **S50sshd**：OpenSSH 服务端的 SysV 开机脚本，也是 ssh 服务，可以关掉。已在 debug 跳过名单中。

## 已做优化

依据 `tspi_action_bsp` 当前提交，已落地的启动相关改动：

- **oem / userdata 改为 ext4**（`429fd1d`）。原先是 ext2，没有 journal，`S21mountall.sh` 每次开机都要 fsck，基线里这一项 6.40s。
- **debug 模式跳过指定服务**（`272f6ae`、`331cb0a`、`47f254c`、`33c99ee`）。`/etc/tspiAction_debug` 为 `true` 时，`boot_timing.sh` 跳过 `S49ntp`、`S50dropbear`、`S50sshd`、`S40rkaiq_3A`。只在 debug 计时路径生效。
- **rkaiq_3A 提前到 S22，相机应用提前到 S23**（`33c99ee`）。`S40rkaiq_3A` 留在原位并加入 skip，避免启动两次。应用已从 skip 名单移除，按该提交应在 S23 拉起。
- **关掉 gmac1，缩短 AP6212 WiFi SDIO 上电延时**（`a028557`）。上电延时从 200ms 改为 50ms。
- **ICM42688P 软复位延时从 100ms 改为 1ms**（`c14d72b`）。该驱动编进内核，时间算在 kernel 阶段。
- **增加启动分段计时**（`a8091ef`）。debug 模式下由 `rcS` 走 `boot_timing.sh`，输出下面这种 per-service 日志。
